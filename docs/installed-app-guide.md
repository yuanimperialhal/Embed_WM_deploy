# Cosmos 相机助手：安装版使用说明

本版面向 Jetson Orin，目标为 Ubuntu 22.04、L4T R36.4.x、arm64、USB 相机；原项目参考环境为 R36.4.3。软件采用 PyQt5；安装包通过系统包管理器安装 Python/Qt/OpenCV、Docker 和 NVIDIA Container Toolkit 等依赖。

0.2.0 起提供首次运行准备向导：模型和镜像从原作者处下载，完成校验后自动保存位置。旧版私有离线部署记录仍兼容，已有的个人配置优先使用。

## 第一次打开

1. 在应用菜单搜索“Cosmos 相机助手”，点击打开。可以把它固定到 Dock。
2. 在准备向导选择自动下载，或使用已有的完整模型目录。自动下载需要访问 https://huggingface.co/embedl/Cosmos-Reason2-2B-W4A16 ，获得作者授权后填写具备模型读取权限的 Token。
3. 点击 **开始准备**。若提示 Docker 权限或 runtime 问题，点击 **配置系统环境…** 并按提示授权；增加用户组权限后需要注销桌面并重新登录。
4. 程序下载固定版本模型并逐文件验证 SHA256，再拉取固定摘要的推理镜像。失败可重试，模型下载支持续传；Token 不写入配置或日志。
5. 准备完成后点击 **进入相机助手**。确认 USB 相机已连接且未被其他应用占用。
6. 点击 **分析一次** 或 **开始连续分析**，应用会自动加载模型并显示回答。

首次下载和模型加载可能需要较长时间，建议预留 25 GiB 空间。DEB 安装阶段只安装软件及系统依赖，大文件在普通用户启动准备向导后下载。系统配置会启用 Docker，必要时重启 Docker，并将用户加入 docker、video 组；界面会先说明影响并请求授权。Docker 组具有管理员级能力。请先安装与设备匹配的 JetPack 和驱动。

如需再次准备，可运行 `cosmos-camera --setup` 或选择“…” → **准备 / 修复运行环境**。已完成准备后的日常使用无需重复下载。

## 模型目录

选择同时包含以下文件的目录，不要只选权重文件，也不要选它的上一级：

- `model.safetensors`
- `config.json`
- `tokenizer.json`、`tokenizer_config.json`
- `preprocessor_config.json`
- 模型发行版的其他 tokenizer、配置和模板文件也应保留。

当前实现对应本项目已验证的 Cosmos 权重和固定镜像，并非任意 VLM 的通用加载器。图片和文字分别来自实时预览与之前的取样帧，回答不是当前视频帧的同步标注。

## 常用操作

| 位置 | 作用 |
| --- | --- |
| 开始连续分析 / 暂停分析 | 开始或取消连续请求；暂停后相机继续显示 |
| 分析一次 | 获取一张最新画面，完成后自动暂停 |
| 相机图标 | 打开或关闭相机 |
| 放大图标 | 在独立窗口查看更大的预览 |
| 顶部模型状态 | 启动模型、取消加载、关闭本窗口启动的模型、查看日志 |
| 时钟图标 | 本次打开窗口后最近 20 次分析 |
| “…” → 设置 | 选择模型目录，保存当前相机和问题 |
| “…” → 准备 / 修复运行环境 | 再次打开下载和环境配置向导 |
| “…” → 检查运行环境 | 不加载模型，检查部署条件 |
| “…” → 打开日志文件夹 | 找到本次和以往使用的日志 |
| “…” → 关于相机助手 | 查看版本、配置和日志位置 |

输入问题会影响下一次分析。想在重启后继续用同一个问题，暂停后进入设置并保存。修改模型目录前需要关闭正在运行的模型。

## 配置和数据保存在哪里

默认使用以下用户目录；若设置了标准 XDG 环境变量，则按该配置保存：

| 内容 | 默认位置 |
| --- | --- |
| 程序 | `/usr/lib/cosmos-camera`（由安装包管理） |
| 配置 | `~/.config/cosmos-camera/settings.json` |
| 日志及结果 | `~/.local/state/cosmos-camera/logs/` |
| 模型缓存 | `~/.cache/cosmos-camera/` |
| 自动下载的模型权重 | `~/.local/share/cosmos-camera/models/<固定版本>/` |
| 自备模型权重 | 用户在设置里选择的目录 |

不需要以管理员身份运行界面。正常使用不保存视频或相机照片；分析文字保存在 JSONL 中。历史按钮显示本次会话的最近 20 条，跨会话记录在日志文件夹里。本版本暂不自动清理旧日志。

## 桌面图标

安装后应用菜单会出现图标，可固定到 Dock。如果需要在桌面放一个快捷方式，在文件管理器中复制 `/usr/share/applications/cosmos-camera.desktop` 到自己的桌面，然后右键选择“允许启动”（若桌面要求）。桌面快捷方式可以删除，不会卸载应用。

开发项目之前生成的桌面图标仍会启动开发目录中的代码。安装版和开发版请一次只开一个，避免争抢 USB 相机。

## 退出、升级、卸载

关闭主窗口，会释放相机和当前请求，并关闭本窗口启动的模型。复用的外部模型服务会保留。

升级前退出应用，再安装新版本的 `.deb`。程序文件会更新；个人配置、日志和单独存放的模型不会被安装包覆盖。

卸载命令为 `sudo apt remove cosmos-camera`。卸载保留个人配置、日志、缓存和模型。确认不再需要时，用户可自行删除这些目录。不要为了卸载程序而删除整个开发项目。

## 出问题时

先打开“检查运行环境”，再看“查看服务日志”。检查通过表示基础文件和权限满足要求，不保证显存、内存或模型兼容性都正确；需要用一次真实调用做最终确认。

模型未找到：运行准备向导或重新选择完整模型目录。下载出现 401/403：确认模型访问已获批，Token 有该模型的读取权限。Docker 权限或 NVIDIA runtime 问题：使用准备向导的系统配置入口；修改用户组后注销并重新登录。相机无法打开：关闭其他预览程序，检查 USB 连接及用户设备权限。不要用 `sudo` 启动整个界面来代替修复权限。
