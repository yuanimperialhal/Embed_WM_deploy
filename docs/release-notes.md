# Cosmos 相机助手发行记录

## 0.2.0

- 增加首次运行向导：检查 Jetson / Docker，下载固定版本模型、逐文件 SHA256 校验并拉取固定摘要的 vLLM 镜像。
- 支持模型断点续传、失败重试、暂停与复用已有模型；下载完成后才保存模型目录，保留已有问题和相机设置。
- 提供单独的系统配置入口，通过桌面管理员授权配置 NVIDIA runtime 和用户组；应用与模型下载保持普通用户权限。
- 安装包声明 Docker / NVIDIA Container Toolkit 等系统依赖，限制在 Ubuntu 22.04 / L4T R36.4.x 使用。
- 增加 GitHub Actions 自动测试、构建、发布 DEB 和 SHA256；提供固定最新版文件名与 README 下载链接配置命令。
- 重写中文 README，补充功能介绍、安装教程、发布指南、升级和卸载说明。
- 公开发布流程不包含模型权重、容器或旧私有离线包；模型从原作者处授权获取。

## 0.1.1

- 增加 Jetson 单文件 `.run` 离线安装器，包含应用、模型、推理镜像、Qt/Python/OpenCV 依赖及安装步骤。
- 文件完整性校验、只校验/只解包模式、本地 APT 依赖源与平台检查。
- 通过系统部署记录自动发现随包模型；保留已有个人配置。
- 兼容 Docker classic/containerd 镜像身份差异，导入后使用验证过的镜像 ID。
- 本离线包严格针对 Ubuntu 22.04 / L4T R36.4.3，需要匹配的 JetPack、Docker 和 NVIDIA runtime。
- 只完成构建及不执行系统安装的检查，另一台设备上的断网安装和真实推理仍待验收。

## 0.1.0

首个可构建 `.deb` 的 Jetson 预览版本。

## 已实现

- 原生浅色 Qt 界面、USB 实时预览、取样缩略图、逐段显示回答。
- 单次/连续分析、取消请求、相机重连、模型生命周期管理。
- 图形设置：选择模型目录，保存当前相机和问题。
- 原子写入配置；配置损坏时保留原文件并提示。
- 安装版程序与用户配置、日志、缓存分开。
- 运行环境检查、日志入口、版本信息。
- 明确文件清单构建 arm64 `.deb`，输出 SHA256 和发行说明文件。

## 当前交付边界

目标为 Ubuntu 22.04 / Jetson L4T R36.4.x，实机参考为 R36.4.3。安装包包含应用与准备向导；Docker / NVIDIA Container Toolkit 由系统包管理器解决，模型和固定镜像由向导下载。JetPack 和驱动仍需预先安装，模型作者的授权访问条件仍需满足。

此版本尚未完成第二台干净 Jetson 的系统安装/升级/卸载验收及长时间稳定性测试。软件层测试、目录解包检查及既有真实 USB + 测试服务记录不能代替这些验收。Windows/macOS、应用内自动更新和跨会话历史界面尚未实现。

完整的发布与验收步骤见 `docs/github-release.md`。
