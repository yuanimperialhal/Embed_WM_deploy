# Cosmos 相机助手：界面操作指南

> 开发参考文档：示例中的 `/path/to/cosmos-camera` 需换成实际源码路径；已安装软件的操作以 [安装版说明](installed-app-guide.md) 为准。

现在使用浅色 Qt 界面：左侧看相机，右侧看回答和输入问题。常用操作留在画面旁边，模型管理和日志放在顶部菜单中。

## 打开后怎么用

1. 在 Jetson 桌面双击 **“Cosmos 相机助手”**。
2. 左边会自动显示 USB 相机的实时画面。
3. 点击右下角 **“开始连续分析”**。
4. 模型尚未启动时，程序会自动加载，右上角显示“模型加载中”。等待期间仍可以看相机。
5. 模型就绪后，右边会逐字显示中文分析结果。

模型首次加载可能需要几分钟，不用重复点击启动。这个窗口需要在 Jetson 已登录的图形桌面上使用。

## 窗口里的按钮

| 按钮 | 作用 |
| --- | --- |
| 开始连续分析 | 自动启动模型，并持续分析最新画面 |
| 暂停分析 / 停止分析 | 停止分析和当前客户端请求，相机画面继续刷新 |
| 分析一次 | 只分析一张最新画面，完成后自动暂停 |
| 相机图标（实时画面右上角） | 关闭或重新打开相机，关闭相机也会暂停分析 |
| 放大图标（相机图标旁边） | 在独立窗口里查看更大的实时画面 |
| 顶部模型状态 | 点击后可启动模型、取消加载、关闭本窗口启动的模型或查看日志 |
| 顶部时钟图标 | 查看本次打开窗口后最近 20 次分析 |
| 顶部“…” | 打开设置、运行环境检查、日志文件夹、说明、版本信息或退出程序 |

把鼠标放到图标上，会显示它的用途。顶部绿色状态点表示模型已就绪，黄色表示正在加载；灰色表示模型尚未启动。

## 选择模型和保存设置

在顶部“…” → **设置**选择完整的 Cosmos 模型目录，再点击 **保存设置**。保存时也会记住当前选择的相机和输入的问题，下一次打开时恢复。当前设备已有的模型目录为 `/path/to/cosmos-camera/models/cosmos-download`。

配置保存在 `~/.config/cosmos-camera/settings.json`。程序正在分析或加载模型时先暂停/等待，再修改设置。更换模型目录前先关闭正在运行的模型服务。

源码版日志仍在项目 `logs/` 下；安装版日志在 `~/.local/state/cosmos-camera/logs/`，可以从“…” → **打开日志文件夹**直接进入。安装与打包过程见 [实操教程](from-demo-to-software.md)。

## 怎么换问题

在右下角 **“想了解什么？”** 下面直接输入问题，也可以点击“描述场景”“有没有人”“物体位置”选择示例。

问题修改后，**下一次分析自动使用新问题**。正在生成的回答仍对应旧问题。如果希望马上切换，先暂停，再开始。

建议一次只问一个简短问题，例如：

> 桌面上有哪些物体？用一句话描述，看不清就说不确定。

## 怎么理解画面和结果

- **左边的大画面**：相机此刻的实时预览。
- **右边的小图片**：这次提交给模型的那一帧。
- **“取样于多少秒前”**：这次分析使用的画面距现在多久。
- **右边的文字**：模型针对取样画面的回答。

模型回答需要时间，因此文字可能与此刻左边的画面不同。程序每次完成后会取最新一帧继续，不会把中间画面排队送给模型。

如果一直回答“画面模糊”，先看左侧预览，调整光线、相机距离和对焦。当前每次独立分析一张图片，不具备连续动作记忆。

## 怎么退出

点击窗口右上角的关闭按钮即可。

程序会停止相机和当前分析，并关闭**由这个窗口启动的模型**。关闭模型可能需要等待几秒。如果打开窗口时已经有其他程序启动的模型服务，界面会复用它，退出时会保留该服务。

## 如果打不开或看不到画面

| 情况 | 处理方法 |
| --- | --- |
| 桌面提示快捷方式不受信任 | 右键快捷方式，选择“允许启动”，再双击 |
| 相机被占用 | 关闭旧的相机预览或采集程序，然后在界面重新打开相机 |
| 相机路径变了 | 先关闭相机，在左边的设备列表选择正确路径，再打开相机；重新插拔设备后可重开界面刷新列表 |
| 模型启动失败 | 点击顶部模型状态或“…”里的“查看服务日志”；设备内存不足时，先关闭自己不需要的应用再重试 |
| 回答没有完整结束 | 把问题改短，要求只回答一句话 |

桌面快捷方式不见了时，也可以使用项目里的 `/usr/share/applications/cosmos-camera.desktop`。备用启动命令是：

```bash
python3 /path/to/cosmos-camera/scripts/camera_ui.py
```

每次使用的结果和模型日志保存在 `/path/to/cosmos-camera/logs/` 下新建的 `camera-ui-日期时间` 文件夹中。普通使用不会自动录制视频或保存相机照片。
